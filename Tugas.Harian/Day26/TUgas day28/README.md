1) Apa beda git add dan git commit?
git add menyiapkan perubahan yang akan masuk ke staging area. git commit menyimpan snapshot dari staging ke history lokal.

2) Kenapa konflik terjadi pada Bagian 6.1, dan bagaimana kamu menyelesaikannya?
Konflik terjadi saat dua branch mengubah bagian yang sama di file yang sama dan Git tidak bisa otomatis menentukan versi yang benar. Solusinya adalah membuka file konflik, memilih isi final yang benar, lalu menambahkan file tersebut dan membuat merge commit.

3) Apa beda fork dan clone? Apa gunanya Pull Request?
clone menyalin repo dari remote ke lokal. fork membuat salinan repo milik orang lain ke akun kita. Pull Request digunakan untuk mengajukan perubahan dari branch kita ke branch tujuan, biasanya main, agar maintainer dapat meninjau dan menggabungkan.
